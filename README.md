# 示範後台｜棠序問策股份有限公司建置（完整網站）

給潛在客戶點著玩的「電商後台」示範：換成你的品牌，就是你的後台。**純前端靜態網站**（不需要伺服器、資料庫），所有資料都是虛構的。

## 怎麼打開
- **最簡單**：雙擊 `index.html`（首頁）。後台在 `app.html`，**顧客看到的商店頁面在 `shop.html`**，都從首頁或右上角按鈕點進去即可。
- 資料存在瀏覽器的 localStorage（金鑰 `tx-demo-v1`）。右上角「重設示範資料」可一鍵還原（會保留目前選的品牌）。
- 想用本機伺服器看：`cd site && python3 -m http.server 8080`，開 `http://localhost:8080/`。

可實際操作的重點：批次取號與標記已處理、標記運送中、新增商品、編輯兩層規格（新增／改名／刪除選項、套用到所有款式、錯誤提示）、取消訂單與退貨（自動回補庫存）、折價券與優惠活動、換品牌、重設。

**綠界規則**：付款設定頁沒有任何向顧客加收刷卡手續費的欄位，也不依金額拒絕訂單，並用白話寫明。

### 後台 ⇄ 商店頁面怎麼連動
| 在後台做的事 | 商店頁面的變化 |
|---|---|
| 商品：新增／上架／下架、改名稱、價格、特價、規格、庫存、介紹 | 商品卡、商品頁、列表、「新上架」馬上變；缺貨顯示「已售完」；庫存 ≤ 低庫存門檻顯示「只剩 N 件」 |
| 網店→外觀與首頁：店名、標語、品牌色、Logo、跑馬燈文字、輪播標題／副標 | 頁首、整站顏色、跑馬燈、首頁大橫幅 |
| 網店→網站選單、頁面 | 頁首選單與頁尾連結（選單文字等於分類名就連到該分類） |
| 設定→運費與出貨、付款 | 結帳可選的取貨方式與運費、付款方式（關掉就不出現）、免運門檻 |
| 行銷→折價券、優惠活動 | 首頁「現在有這些優惠」、購物車可用折扣碼、任選 3 件 9 折 |
| 商品→評價（隱藏／回覆） | 商品頁評價 |
| 顧客→會員等級 | 訂單查詢的等級、結帳時的會員折扣 |
| **商店頁面下單** | 後台「訂單」多一筆（標示「商店頁面下單」）、庫存自動扣、顧客名單新增（手機沒見過就建新顧客）、折扣碼用量 +1 |
| 商店頁面取消訂單／申請退貨 | 後台訂單變「已取消」（庫存補回）／「退換貨」多一筆申請 |

- **同時開兩個分頁**（一個後台、一個商店頁面）：後台一存檔，商店頁面分頁會自動更新並跳出「後台剛剛改了東西」。
- 入口：後台右上角粉紅「看商店頁面」按鈕、商品與網店頁標題右側的按鈕（商品編輯頁會連到「這個商品」的商店頁）、訂單頁的「去商店頁面下一單」、首頁大按鈕與頁尾連結。商店頁面左下角固定「回後台」（會依所在頁面回到對應的後台頁），商品頁另有「去後台改這個商品」，右下角栗栗用氣泡說明「在後台改，這裡馬上變」。
- 商店頁面頁尾與聯絡頁有 LINE 按鈕（`data-line="shop-footer"`、`shop-contact`），和後台一樣走 `config.js`，UTM 的 `utm_content` 是按鈕位置。
- 購物車與登入的手機號碼存在 `tx-cart-v1`、`tx-member-v1`，「重設示範資料」一起清掉。
- **綠界規則**：付款選項只有「信用卡（綠界）／ATM 轉帳／超商取貨付款／貨到付款」，沒有任何手續費欄位，也沒有最低刷卡金額，結帳頁用白話寫明；頁面上明確標示「這是示範，不會真的收錢」，沒有任何卡號輸入欄。
- 動畫：開場由上掉下彈跳、往下捲由下彈起（果凍）、商品卡懸停果凍、加入購物車飛進購物車、換頁左到右糖果條紋掃過（栗栗推著跑）、訂單完成撒彩帶。系統開「減少動態」時全部自動簡化（內容照常顯示，跑馬燈不動）。

## 填入你的 LINE、GA4、Meta Pixel（`config.js`）
```js
window.DEMO_CONFIG = {
  lineUrl: '',        // 例：'https://lin.ee/xxxx' 或 'https://line.me/R/ti/p/@你的ID'
  ga4Id: '',          // 例：'G-XXXXXXXXXX'
  metaPixelId: '',    // 例：'1234567890'
  ...
};
```
- 全部留空也能正常開：按 LINE 按鈕只會跳出提示並在主控台記錄。
- 填了 `lineUrl` 後，每個 LINE 按鈕會自動加上 `utm_source=demo-admin&utm_medium=button&utm_campaign=web-build&utm_content=<按鈕位置>`（位置如 `topbar-cta`、`cta-bottom`、`brand-menu`、`mobile-menu`、`shop-footer`、`shop-contact`）。
- 填了 `ga4Id` 才會載入 GA4，按鈕點擊送出事件 `line_cta_click`（帶按鈕位置、文字、頁面）。
- 填了 `metaPixelId` 才會載入 Pixel，按鈕點擊送出 `Contact`。
- 沒填的追蹤碼，網站**不會**連到第三方。

## 重新產生示範資料
`python3 tools/gen_data.py`（產生 `data/*.json` 與 `data/data.js`；`data.js` 是為了雙擊開檔也能讀到資料）。改字後可 `python3 tools/subset.py` 重新子集化字型。

## 部署（尚未部署，只是準備好）
整個資料夾就是靜態網站，丟到任何靜態主機即可（Cloudflare Pages、Netlify、GitHub Pages、Render Static Site、一般虛擬主機）。**上傳時請排除 `_qa/`（截圖與影片）與 `tools/`**；其餘約 4MB。首頁是 `index.html`，商店頁面是 `shop.html`。

## 授權
- 字型：源泉圓體 TW、Fredoka，皆 SIL OFL 1.1（`fonts/OFL-GenSenRounded.txt`）。
- 動畫程式庫：GSAP 3.15.1（含 ScrollTrigger）、Lenis，放在 `vendor/` 離線使用。**正式上線前請再確認 GSAP 目前授權條款適用於你的用途。**
- 倉鼠與服飾／部分美妝插圖：程式繪製，沒有使用 AI 生圖。生鮮與美妝照片來自 Unsplash（免費授權，已剔除含品牌標誌的照片）。
- 所有品牌、客戶、訂單、顧客資料皆為虛構。

## 已知不足
- 資料是靜態假資料；沒有串接真實綠界、金流或物流。
- 商店頁面：商品圖用現有照片／程式繪製插圖，商品頁縮圖只是同一張圖的不同裁切（沒有多角度實拍）；會員查詢只用手機號碼、沒有密碼（示範用）；商品圖片在商店頁面不會因換品牌色而重畫；沒有金流、發票、真實寄信；新分類沒有商品時不會顯示。
- 後台與商店頁面在「同一個瀏覽器、同一個網址來源」才會連動（資料存在 localStorage，不會傳到伺服器）；換瀏覽器或無痕視窗就是另一份資料。
- 服飾與部分美妝商品用自繪插圖，不是實拍照。
- 首頁動畫在低階手機可能不夠順（系統開啟「減少動態」時會自動簡化）。
- 沒有在真實手機上測過，只用 Chromium 模擬 390px 寬。
- 重新整理或清除瀏覽器資料會讓示範資料回到初始（這是預期行為）。
