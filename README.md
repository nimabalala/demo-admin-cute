# 示範後台｜棠序問策股份有限公司建置（完整網站）

給潛在客戶點著玩的「電商後台」示範：換成你的品牌，就是你的後台。**純前端靜態網站**（不需要伺服器、資料庫），所有資料都是虛構的。

## 怎麼打開
- **最簡單**：雙擊 `index.html`（首頁）。後台在 `app.html`，**顧客看到的商店頁面在 `shop.html`**，都從首頁或右上角按鈕點進去即可。
- 資料存在瀏覽器的 localStorage（金鑰 `tx-demo-v1`）。右上角「重設示範資料」可一鍵還原（會保留目前選的品牌）。
- 想用本機伺服器看：`cd site && python3 -m http.server 8080`，開 `http://localhost:8080/`。

**綠界規則**：付款設定頁沒有任何向顧客加收刷卡手續費的欄位，也不依金額拒絕訂單，並用白話寫明。

- **同時開兩個分頁**（一個後台、一個商店頁面）：後台一存檔，商店頁面分頁會自動更新並跳出「後台剛剛改了東西」。
- 入口：後台右上角粉紅「看商店頁面」按鈕、商品與網店頁標題右側的按鈕（商品編輯頁會連到「這個商品」的商店頁）、訂單頁的「去商店頁面下一單」、首頁大按鈕與頁尾連結。商店頁面左下角固定「回後台」（會依所在頁面回到對應的後台頁），商品頁另有「去後台改這個商品」，右下角栗栗用氣泡說明「在後台改，這裡馬上變」。
- 商店頁面頁尾與聯絡頁有 LINE 按鈕（`data-line="shop-footer"`、`shop-contact`），和後台一樣走 `config.js`，UTM 的 `utm_content` 是按鈕位置。
- 購物車與登入的手機號碼存在 `tx-cart-v1`、`tx-member-v1`，「重設示範資料」一起清掉。
- **綠界規則**：付款選項只有「信用卡（綠界）／ATM 轉帳／超商取貨付款／貨到付款」，沒有任何手續費欄位，也沒有最低刷卡金額，結帳頁用白話寫明；頁面上明確標示「這是示範，不會真的收錢」，沒有任何卡號輸入欄。
- 動畫：開場由上掉下彈跳、往下捲由下彈起（果凍）、商品卡懸停果凍、加入購物車飛進購物車、換頁左到右糖果條紋掃過（栗栗推著跑）、訂單完成撒彩帶。系統開「減少動態」時全部自動簡化（內容照常顯示，跑馬燈不動）。

## 棠序自製外掛：Model Lookbook 模特兒穿搭輪盤 v1.2.0　← 2026-11-05 新增，2026-11-05 加上「外掛開關」
示範我們自己做的外掛：商店頁面有一個**圓形模特兒輪盤**，點模特兒、右側（手機是下方）滑出這套穿搭的單品，照片上的編號熱點和單品一一對應，可單件或「整套加入購物車」。**資料全是虛構、存在 localStorage，和後台、商店頁面共用同一份資料**；作者標示為棠序問策股份有限公司，介面上有「棠序自製外掛」徽章。

### 展示劇情：客人在後台自己打開外掛
1. 外掛**預設關閉**（授權預設有效，不用輸入授權碼）：商店頁面沒有穿搭輪盤，選單也沒有「穿搭輪盤」。
2. 後台「**設定 → 外掛**」有「Model Lookbook 模特兒穿搭輪盤」卡片和一個**大開關**，旁邊有提示氣泡指著開關。
3. 打開開關：6 套穿搭、18 件單品**自動準備好**（不用按匯入）、撒彩帶、出現大按鈕「去商店頁面看看」；商店首頁區塊和選單「穿搭輪盤」**馬上出現**（同一瀏覽器的另一個分頁不用重新整理）。
4. 關閉開關：商店頁面的輪盤區塊、選單、專屬頁全部收起來（穿搭資料保留，再打開就回來）；後台「模特兒穿搭輪盤」管理頁顯示「外掛未開啟」和「開啟外掛」按鈕，不會看到空白列表。
5. 示範穿搭是服飾款：在別家店（晨露鮮蔬、玫瑰小舖）打開外掛時，會自動換到「北風衣櫥」再開啟，並在提示裡說明。外掛開關依各店分開記錄。
6. 「重設示範資料」會讓外掛回到關閉。

| 入口 | 網址 |
|---|---|
| **後台外掛頁（開關在這）** | `app.html#/settings/plugins`；加 `?shop=fashion&hint=1` 會先換到北風衣櫥並顯示大提示氣泡 |
| 首頁「棠序自製功能」亮點 | `index.html`（往下捲，主按鈕「去後台打開外掛」→外掛頁；次按鈕「先看商店頁面」） |
| 示範連結（沒開外掛時會帶到外掛頁） | `shop.html#/lookbook?shop=fashion&demo=1` |
| 商店頁面專屬頁（北風衣櫥，外掛開啟後） | `shop.html#/lookbook`；沒開外掛時顯示「外掛還沒開啟」和「去後台打開外掛」 |
| 商店首頁區塊（外掛開啟後） | `shop.html#/`（區塊「跟著模特兒穿一套」＋選單「穿搭輪盤」） |
| 後台：穿搭列表／編輯／設定／授權 | `app.html#/shop/lookbook`、`#/shop/lookbook/edit/<編號或 new>`、`#/shop/lookbook/settings`、`#/shop/lookbook/license`（外掛沒開時，前三個顯示「外掛未開啟」；授權頁一直可看） |

**商店頁面**：輪盤可左右拖曳／滑動、點兩側模特兒切換、自動輪播（可暫停）、鍵盤左右鍵；點中間模特兒開面板，點照片熱點會讓對應單品亮起；單品選尺寸後「加入購物車」（飛入購物車、用現有購物車，NT$），「整套加入」一次放進這套的所有有貨單品，缺貨或手動輸入的單品會說明沒加入的原因；面板可「看商品頁」。手機：面板變下方彈出，握把往下滑關閉、往上滑拉高，面板內左右滑換下一套。系統開「減少動態」時不旋轉、不彈跳、不自動輪播。

**後台**（網店→「模特兒穿搭輪盤」，分頁有「棠序自製」徽章；外掛關閉時徽章變「未開啟」）：
- 穿搭列表：上下排序、編輯、隱藏／顯示、刪除；仍保留「一鍵匯入示範資料」與「一鍵刪除示範資料」（6 套、18 件，會新增／移除 18 個北風衣櫥商品 `fl01–fl18`，含兩個庫存邊界：`fl05` 尺寸 32 缺貨、`fl09` 尺碼 37 剩 4 件）。
- 編輯穿搭：從 6 張模特兒照片挑一張、**點照片放熱點**（可拖曳微調）、每個熱點連結到店內現有商品，或手動輸入名稱與價格（手動輸入的不能加入購物車）。連結商品的名稱、價格、庫存、規格直接讀商店資料。
- 設定：主題色、面板標題與文字、顯示幾套、間距、自動輪播與秒數、是否顯示價格；有即時預覽與還原預設。
- 授權（**模擬**）：預設「授權有效」（已綁定這個網站、有效至 2027-10-31）。授權頁可切換三種狀態「有效／已過期／未啟用」，一個序號只能啟用一個網站；示範序號 `MLB-K67Q-TBR9-6WPT-HQX9`（有效）、`MLB-EXPD-0000-0000-0001`（過期）、`MLB-USED-0000-0000-0002`（已被別站使用）。未啟用或過期時不能新增穿搭、不能匯入示範，已建立的穿搭仍可編輯、商店頁面照常顯示。「有更新」提示可更新到 v1.2.1。

**連動**：打開／關閉外掛、後台改熱點位置、換照片、新增穿搭、改商品價格或庫存、改設定，商店頁面（同一瀏覽器的另一個分頁）都會自動更新；把穿搭加入購物車→結帳→後台訂單裡有這些品項與尺寸，並標示「商店頁面下單」。關閉外掛不會動購物車和商品。

## 網站風格（外觀主題）　← 2026-11-08 新增
同一套功能，可以換整套外觀。「主題」＝配色、字體、圖案、動畫的組合。
- 預設：`cute` 可愛糖果（v5）。
- 新增：`t02` 夜巷 街頭（黑白街頭選貨風，示範店「巷尾選物 ALLEY 27」）。
- 切換方法：
  1. 網址加 `?theme=t02` 或 `?theme=cute`。
  2. 示範條（最上面黑條）右邊的「風格」按鈕。
  3. 首頁最下面「換成你的品牌」區塊。
  4. 後台「設定 → 店家資料」最下面的「網站風格」卡片。
- 選擇存在 localStorage `tx-skin-v1`。「重設示範資料」不會清掉它。
- 檔案：
  - `js/theme.js`：主題清單與設定（名稱、樣式檔、字體、吉祥物開關、動畫速度、首頁區塊、素材）。放在 `<head>` 所有 CSS 之後。
  - `css/base.css` 的 `:root`：cute 的預設色票（token，就是「顏色、字體的代號」）。
  - `css/themes/t02.css`：T02 全部樣式，選擇器都以 `html.sk-t02` 開頭，不影響 cute。
  - 首頁 `#skinTop`：T02 的街頭首屏（跑馬公告、黑色動態主視覺、故障效果 LOGO、NEW 分類方塊、出清特賣條）。
- **T02 綁定示範店「巷尾選物 ALLEY 27」**（2026-11-08 新增）
  - 資料：`data/alley.json`、`data/alley.js`（由 `tools/gen_alley.py` 產生；不動其他三家店）。16 件街頭服飾、兩層規格（顏色／尺寸或尺碼）、5 件特價、17 筆訂單、10 位顧客。
  - 商品圖：`img/alley/*.webp`（`tools/gen_alley_imgs.py`）。600×600 正方形、淺灰底 #F0F0EE、商品置中留白。來源是既有單品照 `img/lookbook/l*i*.webp`；白色厚底板鞋（a03）用 AI 輔助生成的單品照，商品頁有「商品圖：AI 輔助生成」小字（商品資料 ai:1）；其他圖都不是新生成的。
  - 切到 T02：後台、首頁、商店頁面都自動用巷尾選物。「換品牌」選單在 T02 隱藏（一個主題一家店）。
  - 切回 cute：回到訪客原本選的店（預設晨露鮮蔬）。cute 的換品牌選單不會出現巷尾選物。
  - 穿搭輪盤外掛：巷尾選物和北風衣櫥都算「服飾店」，T02 下可直接開啟外掛、匯入 6 套示範穿搭。巷尾選物的 18 個熱點直接連到店裡的商品（`lbMap`），只補上店裡沒有的 3 件（`lbExtra`：奶油白高領針織衫、深藍錐形長褲、白色牛津襯衫），沒有重複。北風衣櫥照舊補 18 件。
  - 重設示範資料：兩個主題都可用；T02 重設後仍是巷尾選物。
  - 測試：`tools/t02_shop_switch.py [網址]`（22 項）。`tools/run_skin.py t02` 跑舊腳本時，會把「北風衣櫥／fashion」換成「巷尾選物／alley」。

## 填入你的 LINE、GA4、Meta Pixel（`config.js`）
```js
window.DEMO_CONFIG = {
  lineUrl: 'https://line.me/R/ti/p/@664pkwrn',  // 棠序 LINE 官方帳號（2026-11-10 已填）
  ga4Id: '',          // 例：'G-XXXXXXXXXX'
  metaPixelId: '',    // 例：'1234567890'
  ...
};
```
- 全部留空也能正常開：按 LINE 按鈕只會跳出提示並在主控台記錄。
- 目前 `utm: false`：LINE 連結維持原樣（https://line.me/R/ti/p/@664pkwrn），每個 LINE 按鈕都是真連結、新分頁開啟；點擊位置仍會送進 GA4／Pixel 事件（填了 ID 之後）。
- 若把 `utm` 改回物件，每個 LINE 按鈕會自動加上 `utm_source=demo-admin&utm_medium=button&utm_campaign=web-build&utm_content=<按鈕位置>`（位置如 `topbar-cta`、`cta-bottom`、`brand-menu`、`mobile-menu`、`shop-footer`、`shop-contact`）。
- 填了 `ga4Id` 才會載入 GA4，按鈕點擊送出事件 `line_cta_click`（帶按鈕位置、文字、頁面）。
- 填了 `metaPixelId` 才會載入 Pixel，按鈕點擊送出 `Contact`。
- 沒填的追蹤碼，網站**不會**連到第三方。

## 已知不足
- 資料是靜態假資料；沒有串接真實綠界、金流或物流。
- 商店頁面：商品圖用現有照片／程式繪製插圖，商品頁縮圖只是同一張圖的不同裁切（沒有多角度實拍）；會員查詢只用手機號碼、沒有密碼（示範用）；商品圖片在商店頁面不會因換品牌色而重畫；沒有金流、發票、真實寄信；新分類沒有商品時不會顯示。
